# tinypad

A lightweight, no-nonsense Python notepad. It just works.

---

## Why tinypad?

* **Featherlight:** Uses ~1% RAM and <1% CPU.
* **Zero bloat:** No telemetry, no login screens, no Electron wrappers, no nonsense.
* **Actually finished:** Software doesn't need infinite updates to be good. 

## Requirements

* Python 3.x
* Built-in standard library (zero external dependencies)

## Usage

```bash
python tinypad.py
```
