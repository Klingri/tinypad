<h2>:: Why tinypad?</h2>

<p>Tired of text editors that take 500MB of RAM just to open a plain text file? <b>tinypad</b> goes back to basics.</p>

<table>
  <thead>
    <tr>
      <th align="left">Feature</th>
      <th align="left">What it means for you</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td><b>Featherlight</b></td>
      <td>Uses ~1% RAM and &lt;1% CPU. Runs smoothly on ancient hardware.</td>
    </tr>
    <tr>
      <td><b>Zero bloat</b></td>
      <td>No telemetry, no login screens, no Electron wrappers, no nonsense.</td>
    </tr>
    <tr>
      <td><b>Actually finished</b></td>
      <td>Software doesn't need infinite updates to be good.</td>
    </tr>
  </tbody>

<h2>:: Requirements</h2>

<ul>
  <li><b>Python 3.x</b> (Tested and working on standard installations)</li>
  <li><b>Built-in standard library</b> (Zero external dependencies, no <code>pip install</code> required)</li>
</ul>

<br>

<h2>:: Usage</h2>

<p>Clone the repo or just download <code>tinypad.py</code> directly, then run it from your terminal or command prompt:</p>

<pre lang="bash"><code>$ python tinypad.py</code></pre>
